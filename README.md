# Doctor's Clinic / Hospital Management

A responsive clinic and hospital management application foundation.

## Included
- Dashboard and KPI overview
- Patient registration and searchable patient registry
- Appointment and token queue
- Consultation workflow foundation
- Voice consultation entry point
- Prescription workflow foundation
- Laboratory order tracking
- Billing and invoice workflow foundation
- Admission and bed-management foundation
- Pharmacy foundation
- Doctor and staff management foundation
- Responsive desktop/mobile UI
- Browser persistence for demo records

## Roadmap
1. Production database and API
2. Authentication and role-based access
3. Patient EMR and clinical encounters
4. Voice transcription, translation, and structured consultation
5. Doctor-reviewed prescription generation
6. Lab, pharmacy, billing, admission and discharge workflows
7. PDF/print generation
8. Audit logging, backups, encryption and production hardening

> Clinical AI features are intended to assist clinicians. Prescriptions and clinical records must be reviewed and approved by an authorized clinician before use.
